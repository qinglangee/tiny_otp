## 踢你OTP（TinyOTP）功能介绍

踢你OTP 是一个离线优先的动态验证码应用。它用于保存兼容 TOTP 标准的验证器密钥，并按时间生成一次性验证码。验证码由应用在本机计算；添加账号、查看验证码和搜索账号不需要网络连接。

账号数据保存在本机的加密存储中。导出备份时，应用会再用独立的备份密码加密备份文件。请妥善保管备份密码，忘记后无法从备份文件中恢复账号。

> 目前页面上的按钮和菜单仍显示英文。下文同时列出界面英文名称，方便按步骤操作。

## 添加验证器账号

### 扫描二维码

1. 在要启用双重验证的网站或服务中，选择使用验证器应用（Authenticator app），并打开设置二维码。
2. 在踢你OTP 首页点右下角 **Add account**，再选择 **Scan a setup QR code**。
3. 首次扫码时，按系统提示允许相机权限。相机只在进入扫码页面时使用。
4. 将二维码放入扫描框。扫描结果会在本机解析。
5. 核对显示的服务名称、账号名称和验证码参数，然后点 **Save** 保存。
6. 回到服务的双重验证设置页面，输入踢你OTP 显示的当前验证码，完成该服务的验证器绑定。

二维码无法扫描时，可返回首页改用手动输入。如果服务提供恢复码，请按服务的说明另行安全保存；恢复码不是 TOTP 密钥，也不能用踢你OTP 生成。

### 手动输入

1. 点 **Add account** → **Enter details manually**。
2. 填写 **Issuer / service**（服务名称）、**Account name**（用户名、邮箱或账号备注）和 **Base32 secret**（服务提供的验证器密钥）。
3. 按服务提供的信息选择 **Algorithm**（算法）、**Digits**（验证码位数）和 **Period (seconds)**（有效时间步长）。通常默认值是 SHA1、6 位、30 秒；若服务明确提供了其他参数，应使用服务给出的值。
4. 点 **Review** 检查服务名称和账号信息，确认无误后点 **Save**。

密钥通常只会在服务设置验证器时显示。请勿把密钥发给他人或粘贴到聊天、邮件等不受信任的位置。相同服务名称和账号名称不能重复添加。

## 查看和使用验证码

- 首页账号卡片显示服务名称、账号名称、当前验证码和剩余有效时间。验证码会根据当前系统时间刷新。
- 点账号卡片即可复制当前验证码。复制内容只包含验证码；页面会显示 **Code copied** 提示。
- 验证码临近过期时，可以等新验证码刷新后再输入。网站和应用通常只接受当前时间窗口内的验证码。
- 手机时间不准确时，验证码可能被服务拒绝；请先在系统设置中启用自动设置日期和时间。

## 搜索、排序、编辑和删除

### 搜索

账号列表上方的 **Search accounts** 输入框支持按服务名称或账号名称查找。清空搜索框即可显示全部账号。

### 排序

点 **Sort by** 右侧的选项，可按 **Issuer**（服务名称）或 **Account name**（账号名称）排序。

### 编辑

1. 在对应账号卡片右上角点 **⋮**（更多操作）。
2. 选择 **Edit**。
3. 修改 **Issuer / service** 或 **Account name**，再点 **Save**。

编辑只修改显示名称，不会更改该账号的 TOTP 密钥或算法参数。若要更换验证器密钥，请确认网站端的密钥变更后，再按网站提供的新设置添加相应账号。

### 删除

1. 在对应账号卡片右上角点 **⋮**，选择 **Delete**。
2. 核对确认提示中的服务和账号信息；点 **Delete** 才会从本机移除，点 **Cancel** 则保留。

删除账号不会关闭服务网站上的双重验证。请先确认仍能通过网站提供的其他验证或恢复方式登录。

## 创建加密备份

1. 点首页右上角的加密备份图标，进入 **Encrypted backup**。
2. 点 **Create encrypted backup**。
3. 设置并确认一个至少 12 个字符的独立备份密码。该密码不同于手机解锁密码，也不依赖原手机的安全密钥。
4. 在系统文件保存窗口中选择位置并保存 `tinyotp-backup.tinyotp` 文件。
5. 把备份文件和密码妥善保存。仅有文件而没有密码无法恢复；也不要把密码和备份文件放在同一个不安全的位置。

备份文件经过加密，不是明文密钥导出。应用不会自动上传备份；保存位置由你在文件窗口中选择。

## 从备份恢复

1. 在新设备安装并打开踢你OTP，进入首页右上角的加密备份页面。
2. 点 **Restore from backup**，在文件选择窗口中选择 `.tinyotp` 备份文件。
3. 输入创建该备份时设置的密码。
4. 核对恢复预览显示的账号数量。如果当前设备已有账号，恢复会替换现有账号；确认后点 **Restore**，取消则不会执行恢复。
5. 恢复完成后，账号会使用当前设备的本地密钥重新加密保存。打开账号卡片确认验证码正常显示，再到对应服务验证。

密码错误、文件损坏或格式不支持时，应用会显示错误并停止恢复。不要删除原设备上的账号，直到确认新设备恢复成功并可正常登录相关服务。

## 当前不包含的功能

当前版本暂不提供应用锁、生物识别、云同步或账号登录功能。深色模式也暂未提供。加密备份由用户手动保存和恢复。
